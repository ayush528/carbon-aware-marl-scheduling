# docs

| Folder | Contents |
|---|---|
| `research/` | Feasibility report (MD/PDF/DOCX), executive summary, research notes A–D, `findings-and-plan.md` (roadmap), source list |
| `datasets/` | `DATASETS.md` catalog (URLs, licenses, audit status) + `data-audit/` evidence base (README, verification tables, small raw samples, fetch scripts) |
| `deliverables/` | Project proposal deck, dataset-comparison spreadsheet |
| `notes/` | Working TODO, decision log (ADRs) |

Rules: research sourced from the internet keeps its URL and access date; any
dataset used by an experiment must be in `DATASETS.md` and in the
experiment's config `data:` list.
